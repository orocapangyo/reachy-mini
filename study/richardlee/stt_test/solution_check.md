## 평가 지표

### 1. VAD 지연 시간 (Voice Activity Detection Latency)

> **비유: "대화할 때 상대방이 언제 말을 끝마쳤는지 눈치채는 센스"**
> 
- **정의**: 사람이 말을 끝낸 순간(실제 침묵 시작)부터, VAD(음성 감지기)가 **"아! 상대방이 말을 완전히 끝냈구나!"**라고 최종 판단을 내릴 때까지 걸리는 대기 시간입니다.
- **왜 중요할까요?**
    - **이 시간이 너무 짧으면 (< 200ms)**: 사용자가 말하는 도중에 숨을 고르느라 잠깐 0.3초만 쉬어도 로봇이 "말이 끝났다"고 오해해서 대답을 해버리는 **'말 끊기 현상'**이 발생합니다.
    - **이 시간이 너무 길면 (> 1000ms)**: "안녕?"이라고 말을 끝냈는데도 로봇이 1초 넘게 가만히 침묵을 지키다 뒤늦게 답하는 **'어색한 정적'**이 생깁니다.
    - **가장 자연스러운 골든 타임**: 보통 **300ms ~ 600ms** 사이로 세팅하는 것이 가장 대화가 자연스럽습니다.

### 2. STT 추론 시간 (Speech-to-Text Inference Latency)

> **비유: "상대방이 한 말을 머릿속으로 받아 적고 번역하는 데 걸리는 뇌의 연산 속도"**
> 
- **정의**: VAD가 잘라준 오디오 파일 데이터를 Whisper 같은 STT 인공지능 모델에 넘겨준 순간부터, **글자로 완전히 번역해 출력할 때까지 걸린 순수 컴퓨터 연산 시간**입니다.
- **왜 중요할까요?**
    - 이 시간은 전적으로 **하드웨어 사양(CPU/GPU)**과 **AI 모델의 크기**에 따라 결정됩니다.
    - 말을 다 하고 나서 로봇이 생각하는 데 시간을 얼마나 쓰느냐를 결정하는 지표입니다.
    - 일반 PC(CPU) 환경에서 `base` 모델 기준 **500ms(0.5초) 이하**로 끝나야 사용자가 지연을 거의 느끼지 않는 훌륭한 속도입니다.

### 3. CER (Character Error Rate, 음절 오류율)

> **비유: "받아쓰기 시험에서 글자를 얼마나 정확하게 맞췄는지 세는 점수"**
> 
- **정의**: 사람이 말한 정답 문장(Ground Truth)과 AI가 받아 적은 문장(Prediction)을 비교하여, **글자(음절) 단위로 얼마나 많이 틀렸는지**를 백분율(%)로 나타낸 것입니다.
- **계산 원리**:
    - 만약 정답이 **"로봇공학"** (4글자)인데, AI가 **"로보공합"**으로 적었다면:
        - '봇'을 누락했고 ('보'로 인식), '학'을 '합'으로 틀리게 적었으므로 2글자가 에러입니다.
        - 따라서 오류율은 **50%**가 됩니다. (즉, CER이 낮을수록 정확도가 높은 것입니다.)
- **왜 한국어에서 WER(단어 오류율)보다 CER(음절 오류율)이 더 중요할까요?**
    - 한국어는 조사("~이/가/을/를")가 단어 뒤에 붙고 띄어쓰기 규칙이 매우 복잡합니다.
    - 만약 AI가 문맥을 완벽히 이해하고 적었어도 띄어쓰기나 조사 하나만 틀려도 단어 단위 채점(WER)에서는 단어 전체가 오답 처리됩니다.
    - 그래서 한국어 음성인식 평가 시에는 띄어쓰기와 문장 부호를 떼고 오직 **순수 글자 하나하나가 맞았는지를 체크하는 '공백 제외 CER'**을 가장 신뢰도 높은 표준 지표로 삼습니다. (보통 CER 10% 이하, 즉 정확도 90% 이상이면 상용화가 가능한 최우수 수준입니다.)
- CER = {S + D + I} /{N}
    - S (Substitution): 잘못 인식해서 바뀐 글자 수 (예: '로봇' ➡️ '노봇')
    - D (Deletion): 인식하지 못하고 빠진 글자 수
    - I (Insertion): 안 한 말을 문맥상 새로 집어넣은 글자 수
    - N: 정답 문장의 총 글자 수
- **평가 기준:** 실시간 대화 환경에서 CER 10% 이하(정확도 90% 이상)이면 실전 배치에 문제가 없는 훌륭한 수준입니다.

## **💡 결과 분석 코멘트**

### **1. STT 정확도 (Accuracy) - 🟢 최우수**

- **평균 CER (공백제외)**: `7.5%` (정확도 `92.5%`)
- **분석**: 한국어의 띄어쓰기 한계를 보정한 CER 지표에서 `7.5%`로 서비스 실전 배치가 가능한 뛰어난 수준을 나타냈습니다. "로봇 팔" ➡️ "로봇파" 처럼 동음이의어 또는 연음 현상으로 인한 아주 미세한 오차가 존재하며, 영어 또한 "Reachy" ➡️ "Reachie" 같은 브랜드 고유 명사 표기 문제 외에는 완벽한 문장 복원을 이루었습니다.

### **2. VAD 지연 시간 (VAD Latency) - 🟢 적절**

- **평가 결과**: 신규 TTS 합성 샘플들에서 VAD 지연이 **정확히 `700.0ms`*로 완벽하게 측정되었습니다.
- **이유**: TTS 오디오 파일 끝에 침묵 영역이 충분히 포함되도록 VAD 종료 감지가 정상적으로 일어났으며, 이는 설정된 침묵 판단 임계시간(600ms)과 전후 패딩(100ms)의 합인 700ms가 타임라인에 명확히 표현된 결과입니다.
- *기존 수동 녹음의 경우, 말을 마친 뒤 600ms를 채 쉬기 전에 파일 자체가 끊겨 인위적인 끝부분 지연으로 왜곡되었던 점이 검증되었습니다.*

### **3. STT 추론 속도 (Inference Speed) - 🟡 경고 (CPU int8 환경)**

- **평균 추론 지연**: `664.6ms` (0.66초)
- **분석**: CPU 환경에서 `base` 모델을 int8 양자화하여 동작시켰음에도 700ms 미만으로 준수하게 도출되었습니다. 다만 실시간 반응성 극대화를 위해서는 모델 크기를 `tiny`로 낮추거나 GPU 자원을 동원해 `300ms 이내`로 끌어내리는 대안을 검토해볼 수 있습니다.

| **`medium`** | 769M (7억 6천만) | ~5 GB 내외 | 🐢 **2x** | **높음.** 정확도는 매우 뛰어나나 CPU 단독 구동 시 지연 시간이 1.5~2초 이상으로 늘어나 실시간 대화 흐름이 다소 굼떠짐. |
| **`large-v2` / `large-v3`** | 1.5B (15억) | ~10 GB 내외 | 🛑 **1x** (기준점) | **최상.** 최고의 한국어 정확도를 보여주지만 CPU로 돌리기엔 연산량이 너무 무거워 실시간 스트리밍 대화 시 Lag이 매우 심해짐 (GPU 필수). |

## ⚡ 속도와 정확성을 모두 잡은 특수 모델 라인업

표준 모델 외에 최신 `faster-whisper` 생태계에서 자연어 대화용으로 자주 활용하는 고효율 모델들입니다.

### 1. `large-v3-turbo`

- **특징:** OpenAI가 대형 모델의 레이어 수를 줄여 추론 속도를 대폭 개선해 출시한 모델입니다.
- **장점:** 기존 `large-v3`와 거의 대등한 최고 수준의 한국어 정확도를 유지하면서, 속도는 `small`이나 `medium` 수준에 준할 정도로 극적으로 빨라졌습니다. GPU 환경은 물론 사양이 좋은 최신 CPU PC에서도 도전해 볼 만한 매력적인 대화용 모델입니다.

### 2. Distil-Whisper 계열 (`faster-distil-whisper-large-v3` 등)

- **특징:** 지식 증류(Distillation) 기법을 사용해 모델 무게를 최소화한 버전입니다.
- **장점:** `large` 모델의 뛰어난 소음 억제력과 문맥 이해도를 유지하면서도 연산 속도와 메모리 사용량을 절반 가까이 줄였습니다. 오픈소스 진영(`Systran`)에 고속 변환 포맷이 풀려 있어 `faster-whisper` 코드에서 모델 이름만 변경하면 바로 사용 가능합니다.
