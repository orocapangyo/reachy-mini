- 최신 음성 인식 알고리즘 트렌드
1. OpenAI Whisper (대세 알고리즘)
현재 학계와 산업계에서 가장 많이 쓰이는 트랜스포머(Transformer) 기반의 오픈소스 음성 인식 모델입니다.

장점: 한국어 인식률이 압도적으로 높고, 주변 소음(시뮬레이터 모터 소리 등)이 섞여도 문맥을 파악해 정확하게 받아적습니다.

로봇 적용 점수: ⭐️⭐️⭐️⭐️⭐️ (소형화된 Whisper-tiny 또는 Whisper-base 모델을 쓰면 로컬 PC에서 실시간 처리가 가능합니다.)

2. Faster-Whisper (로봇 실시간 제어용)
기존 OpenAI Whisper를 C++ 기반(CTranslate2)으로 재구현하여 속도를 4배 이상 끌어올린 라이브러리입니다.

장점: 메모리를 적게 먹고 반응 속도가 빨라, 로봇이 사람 말을 듣고 '즉시' 반응해야 하는 인터랙션에 최적입니다.

- 알고리즘 소스
1. 필수 라이브러리 설치
가상환경((.venv))에서 대용량 인공지능 모델 처리를 위한 라이브러리를 설치합니다.
//
PowerShell
uv pip install faster-whisper
//

- 정리
1. 데이터 전처리(Audio Normalization)의 중요성:
기존 Google STT는 날것의 바이너리(tobytes())를 그냥 던져주면 알아서 처리했습니다.
 하지만 최신 딥러닝 모델(Whisper 등)은 입력 데이터를 -1.0 ~ 1.0 사이의 수학적 행렬로 바꾸어 주어야 인공신경망이 연산을 시작할 수 있습니다. 

2. 채널 통합(Stereo to Mono):
로봇의 귀(마이크)는 2개(좌/우)이지만, 대다수의 음성인식 AI는 1개의 채널만 집중해서 듣도록 설계되어 있습니다. 
그래서 중간에 np.mean을 통해 소리를 하나로 합쳐주는 트릭이 들어간 것입니다.
