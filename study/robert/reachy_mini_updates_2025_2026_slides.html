01. 하드웨어 머리 메커니즘

스튜어트 플랫폼(6-DOF 병렬) & 기구학

  • 구조: 베이스의 6개 모터 → 암(arm) 회전 → 로드(rod) → 볼조인트 → 상단 머리. 6링크 길이 조합으로 6자유도 결정
  • 기구 파라미터: motor_arm_length, rod_length, 모터 배치, head_z_offset (kinematics_data.json)
  • 장점: 병렬 구조라 고강성·하중 분산 → 작은 모터로 정밀 제어
🧮 3종 기구학 엔진

해석적 IK + 뉴턴법 FK(Rust 바인딩) · Placo 최적화 · 신경망 근사. automatic_body_yaw로 몸통이 회전 범위를 보완.

02. 미디어 백엔드 GStreamer

GStreamer 표준 백엔드 도입

  • 기존 한계: 미디어 처리 백엔드가 네트워크·클라이언트 OS에 따라 잦은 끊김과 높은 자원 점유율
  • GStreamer 채택: 기본값을 GStreamer로 전환 → OS별 하드웨어 가속(인코딩/디코딩) 활용
  • 구조 표준화: 디바이스 소스(카메라/마이크)→네트워크 송출을 엘리먼트 그래프로 일원화 → 교체·디버깅·확장 용이
💡 호환성 모드 튜닝
대시보드 앱 실행 시 디바이스·환경에 따라 미디어 백엔드가 즉시 호환성 모드로 동작하도록 데몬 내부 실행 인자가 대거 튜닝되었습니다.
02. 미디어 백엔드 WebRTC 양방향

WebRTC 양방향 오디오 & 레이텐시 최적화

  • 양방향 실시간 오디오: 로봇 스피커 출력 + 마이크 입력 동시 송수신 → 대화형 앱 기반

02. 미디어 백엔드 디바이스 공유 · DoA

오디오 장치 디텍션 & 디바이스 공유

🎥 PipeWire 기반 디바이스 공유

카메라·마이크 스트림을 PipeWire 환경으로 유도하여, 로봇 제어 데몬과 사용자 앱이 동시에 같은 입력 장치에 접근하도록 설계(독점 방지).

🎙️ PulseAudio 폴백 확장

비-PipeWire(일반 PulseAudio) 구형 배포판에서도 오디오 디렉팅이 에러 없이 폴백되도록 탐지 로직 최적화.

📍 Sound DoA 무선 지원

reSpeaker 마이크 어레이 카드 번호를 인식해 소리 방향을 식별하고 머리를 돌리는 DoA의 무선 모드 지원 강화.

03. 하드웨어/모터 플래싱 로직

부팅 시 조건부 플래싱으로 수명 연장

  • 기존 고질병: 기동 시마다 전체 모터 펌웨어를 재플래싱
  • 문제점: 부팅 30초 이상 연장, EEPROM 수명 단축, 내구도 하락
  • 지능형 검증: 현재 파라미터를 고속 스캔 → 불일치 모터만 부분 플래싱
  • 효과: 정상 시 약 1초 기동, 불필요한 쓰기 사이클 방지
graph TD Start[부팅 시 데몬 시작] --> Check{모터 파라미터 체크} Check -- 일치 --> Skip[플래싱 생략 / 약 1초 기동] Check -- 불일치 --> Reflash[대상 모터 부분 플래싱] Skip --> Ready[가동 준비 완료] Reflash --> Ready
03. 하드웨어/모터 안전 · 전력

안전 토크 잠금 & 과전류 보호 개선

🛡️ 앱 종료 시 안전 토크 잠금 (enable_torque)

앱·대시보드를 닫거나 예외로 종료되는 순간, 머리/링크가 중력으로 떨어져 스튜어트 기구가 파손되지 않도록 모터 토크를 즉시 강제 활성화해 자세를 고정.

⚡ 과전류 보호 임계치 재보정

신형 전원 어댑터 출력 수준에 맞춰 과전류 센서의 안전 마진을 재조정. 격렬한 매크로 동작 시 시스템 전원(GPIO)이 즉시 차단되던 현상을 예방.

03. 하드웨어/모터 모터 CLI

모터 모니터링 CLI 고도화

TTL 데이지체인의 9개 서보 중 어느 것이 응답하지 않는지 현장에서 바로 진단합니다.

# 무선 모드 또는 특정 시리얼 포트를 직접 지정해 점검
scan_motors --wireless --port /dev/ttyUSB0
  • --wireless / --port: 무선·멀티 포트 환경에서도 연결된 모터 ID/상태 즉시 확인
  • ID 기반 단독 셋업: 이름(name)을 거치지 않고 순수 하드웨어 ID로만 매핑 → 명칭 충돌 근본 해소
04. 플랫폼 & 앱 환경 Windows

Windows OS 풀 체인 호환성

📁 임시 폴더 리소스 유출 방지

빌드 중 임시 파일 미해제로 발생하던 파일 잠김·삭제 에러(PermissionError)를 컨텍스트 매니저로 안전 폐기되도록 해결.

🌐 get_ip_address 보정

리눅스 전용 소켓에 종속됐던 IP 검색·파싱을 윈도우 소켓에서도 동작하도록 수정(대시보드 접속 주소에 직접 영향).

⚠️ UnicodeEncodeError 방어
이모지·다국어 특수문자가 앱 이름/경로에 섞여도 Windows에서 빌드가 크래시되지 않도록 문자열 변환 과정을 전면 정비.
04. 플랫폼 & 앱 환경 App Assistant · venv

App Assistant & 가상환경(venv) UI

  • 대화 앱 템플릿: --template conversation으로 음성 상호작용 앱 스켈레톤 자동 생성
  • 패키지 충돌 방지: 생성 시 고유 접미사 부여로 네이밍 충돌 예방
  • 원클릭 venv 초기화: 라이브러리 충돌 시 대시보드 "Reset Venv" 버튼으로 복구
# 대화형 앱 스켈레톤 생성
reachy-mini-app-assistant create \
  --template conversation
💡 대시보드 뷰 추가
"Virtual Environment Reset" UI 컴포넌트가 신규 추가되어 패키지 꼬임을 브라우저 클릭만으로 수리.
