## 1. 지연 시간 (Latency) 평가 지표 및 측정법

자연스러운 대화를 위해서는 아래 세 가지 구간의 시간을 각각 체크하여 어느 곳에서 병목이 생기는지 확인해야 합니다. 파이썬의 `time.perf_counter()`를 사용하면 밀리초(ms) 단위로 정밀하게 측정할 수 있습니다.

### ① VAD 지연 시간 (VAD Latency)

* **정의:** 사람이 말을 끝낸 순간(실제 침묵 시작)부터 VAD가 "말이 끝났다!"라고 판단하고 신호를 주기까지 걸리는 시간입니다.
* **평가 기준:** 보통 **300ms ~ 500ms** 사이로 설정합니다. 이 시간이 너무 짧으면 숨을 잠깐 고를 때 말이 끊기고, 너무 길면 로봇이 한참 뒤에 반응하게 됩니다.

### ② STT 추론 시간 (Inference Latency) ⭐️ 가장 중요

* **정의:** VAD가 잘라준 오디오 데이터를 `Faster-Whisper`에 넘겨준 순간부터, 텍스트 변환 결과가 완벽히 출력될 때까지 걸리는 순수 연산 시간입니다.
* **측정 코드 예시:**
```python
import time

start_time = time.perf_counter()
segments, _ = model.transcribe(audio_buffer, beam_size=5)
text = "".join([seg.text for seg in segments])
end_time = time.perf_counter()

print(f"STT 순수 연산 시간: {(end_time - start_time) * 1000:.2f} ms")

```


* **평가 기준:** 일반 PC(CPU, int8) 환경에서 `base` 모델 기준 **500ms(0.5초) 이하**로 떨어지면 합격입니다. 1초를 넘어가면 모델 크기를 낮추거나(`tiny`), 양자화 설정을 다시 점검해야 합니다.

## 2. 정확성 (Accuracy) 평가 지표

음성인식의 정확성을 평가할 때는 사람이 직접 받아 적은 정답 텍스트(Ground Truth)와 AI가 인식한 텍스트(Prediction)를 비교하는 알고리즘 지표를 사용합니다.

### ① CER (Character Error Rate, 음절 오류율) ── 한국어 필수 지표

한국어는 조사와 어미가 발달하고 띄어쓰기가 복잡하기 때문에, 단어 단위보다는 **글자(음절) 단위**로 정확도를 깨는 CER을 주로 사용합니다.

* **계산 방식:** 
$$CER = \frac{S + D + I}{N}$$


* $S$ (Substitution): 잘못 인식해서 바뀐 글자 수 (예: '로봇' ➡️ '노봇')
* $D$ (Deletion): 인식하지 못하고 빠진 글자 수
* $I$ (Insertion): 안 한 말을 문맥상 새로 집어넣은 글자 수
* $N$: 정답 문장의 총 글자 수


* **평가 기준:** 실시간 대화 환경에서 CER 10% 이하(정확도 90% 이상)이면 실전 배치에 문제가 없는 훌륭한 수준입니다.

### ② WER (Word Error Rate, 단어 오류율)

* **정의:** 띄어쓰기(어절) 단위로 오류를 측정하는 지표입니다.
* **주의점:** 한국어는 띄어쓰기 규칙이 까다로워 AI가 문장은 완벽히 알아들었어도 띄어쓰기 하나 틀리면 오류로 잡히기 때문에, 한국어 평가 시에는 CER에 비해 조금 엄격하게(낮게) 나오는 경향이 있습니다.
